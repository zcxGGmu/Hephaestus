# Analysis Docs

This directory contains project analysis documents rewritten with ASCII file names to avoid GitHub filename and encoding issues.

## Documents

- [project-analysis.md](project-analysis.md)
  High-level project analysis, architecture summary, strengths, and risks.

- [source-map-and-runtime.md](source-map-and-runtime.md)
  Source code map, backend/frontend module guide, and execution flow.

- [deployment-checklist.md](deployment-checklist.md)
  Minimal local deployment checklist and troubleshooting notes.

## Why These Files Were Rewritten

The earlier versions used Chinese file names and content that did not display reliably on GitHub in this repository context.
These files were regenerated with:

- ASCII file names
- clean UTF-8 text
- simpler structure for long-term maintenance
